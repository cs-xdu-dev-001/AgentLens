# Codex式纯白聊天输入区设计

## 目标

在不改变KnowFlow AI功能、导航和消息结构的前提下，把聊天工作区收敛为更接近Codex的操作界面：纯白主画布、清晰中心轴和完整的大输入面。

## 视觉结构

- 主聊天画布、消息区和输入框使用纯白背景。
- 侧栏保留极浅灰背景和细分隔线，避免整页失去层次。
- 空状态标题与输入框共享同一中心轴。
- 输入框桌面端最大宽度860px，采用约22px圆角、浅灰边框和克制的下投影。
- 输入区上层用于文本和Skill；下层为工具条。
- 工具条左侧只放附件入口，右侧依次放模型选择器和发送按钮。
- 模型选择器保持无重边框样式，仅在悬停或键盘聚焦时显示状态。

## 交互和响应式

- 保留现有附件、Skill、知识库、模型切换、停止生成和发送逻辑。
- 文本输入可随内容增长，但空状态保留稳定的大输入面。
- 窄屏下输入框距边缘12px，底部工具条不换行，模型名称允许截断。
- 键盘焦点清晰可见；鼠标点击不出现厚重双描边。
- 深色模式维持现有暗色语义，不强制使用白底。

## 不做的内容

- 不新增麦克风、推理强度或权限按钮。
- 不修改后端接口、模型配置或消息数据结构。
- 不重做侧栏、运行抽屉和管理页面。

## 验收标准

- 桌面端和420px窄屏下，标题与输入框中心一致。
- 浅色模式聊天主画布和输入框为纯白。
- 空输入框明显高于当前紧凑表单，并呈现Codex式上下结构。
- 加号位于左下，模型和发送位于右下且垂直居中。
- 现有聊天、模型选择、附件和Skill测试全部通过。
- 前端生产构建通过，布局扫描无未解释问题。
