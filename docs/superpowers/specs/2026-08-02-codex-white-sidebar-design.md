# Codex式纯白侧栏与知识库设计

## 目标

在不删除入口、不改变会话和导航逻辑的前提下，收敛左侧栏与知识库页面的颜色、密度和层级，使界面接近Codex的克制工作台。

本设计覆盖此前“侧栏保留极浅灰背景”的约定：浅色模式侧栏、知识库顶栏、知识库列表栏和主工作区统一改为纯白。

## 颜色系统

- 页面、侧栏、顶栏、知识库列表栏和主工作区使用`#fff`。
- 分区仅使用`1px #e7e7e7`边线和留白，不使用偏黄、偏蓝或成片灰底。
- 悬停使用`#f5f5f5`，当前项使用`#ececec`。
- 正文使用近黑色，次要文字使用中性灰；核心信息不依赖小字号或低对比度文字。
- 主操作按钮保持黑底白字。
- 青绿色仅用于键盘焦点、连接成功等语义状态，不作为普通导航背景或装饰边框。
- 深色模式沿用现有暗色语义，不强制套用浅色值。

## 左侧栏

- 展开宽度为252px，折叠宽度为56px。
- 品牌区缩小，只保留Logo、名称和收起按钮，不显示“工作台”等解释文字。
- “新对话”、搜索、会话、知识库、Skills、记忆、工具与MCP、设置和账号功能全部保留。
- 功能入口统一为36px扁平行，图标、文字和选中态共用同一对齐轴。
- 搜索框弱化为侧栏工具，不呈现独立表单卡片。
- 删除重复的“历史记录”总标题，仅保留“今天”“最近7天”“更早”等时间分组。
- 会话行不显示时间副文案；悬停时显示更多操作，当前会话使用中性灰底。
- 底部工具入口保持常驻，账号固定在最下方；不把设置收进账号菜单。
- 折叠状态只显示图标，保留工具提示、键盘焦点和现有展开逻辑。

## 知识库页面

- 顶栏、知识库列表栏、标签区、表单区和空状态统一为纯白。
- 左侧知识库列表通过右边线与主区分隔，不使用独立灰色面板。
- 搜索框、选择器和空状态使用白底细边框；悬停和聚焦只改变边框或中性灰背景。
- 标签当前态使用文字加底边，不使用灰色块状底。
- 空状态删除虚线灰卡片感，使用正文级文字和必要操作。

## 响应式与无障碍

- 桌面端侧栏宽度变化不得挤压聊天输入区或运行抽屉。
- 760px以下沿用现有顶部导航形态，保证按钮至少40px可点击区域。
- 所有交互保留清晰的`:focus-visible`状态，颜色对比满足正文可读性。
- 长会话名、知识库名和账号信息单行截断，不推动图标和操作按钮。

## 不做的内容

- 不删除、合并或迁移导航入口。
- 不修改会话、知识库、认证和页面路由数据流。
- 不重做聊天输入框、运行抽屉及深色模式视觉体系。
- 不引入新的UI组件库或图标依赖。

## 验收标准

- 浅色模式下侧栏与知识库页面的主要底色均为`#fff`，只出现规定的中性状态色。
- 展开侧栏为252px，折叠侧栏为56px，全部入口仍可访问。
- 侧栏不存在重复“历史记录”标题、两行会话元数据或卡片式搜索框。
- 知识库页面不再出现偏黄、偏蓝或大面积浅灰分区。
- 桌面端与420px窄屏截图无溢出、遮挡或错位。
- 全部`tests/check_*.py`、前端生产构建和`git diff --check`通过。
